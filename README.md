# ai-chat

Create a chatbot web application,
- Application should be similer to chatGPT
- using http api it should interact with LLM
- it should maintain session for each user
- And i should have feature to intergrate MCP which i have created
- Is should have light and dark theme
- use angular to buid the AI 
- Use bootstrap for css
- no unit test isrequired
- CI/CD deployment is not needed for now
- use @modelcontextprotocol/sdk version 1.25.1


Technical Stack Summary
Frontend: Angular 19+ with TypeScript
Styling: Bootstrap 5+ with custom theming
State Management: RxJS + Angular Services
HTTP Client: Angular HttpClient with interceptors
Authentication: JWT-based or session-based
Build Tool: Angular CLI with Webpack
